# SportReserve

Sistema de reserva de quadras esportivas, com autenticação e gerenciamento de horários em tempo real.

🔗 **Demo:** https://inspiring-otter-2c7669.netlify.app
🛠 **Stack:** HTML, CSS, JavaScript, JSON Server

## Funcionalidades
- Cadastro e login de usuário
- Reserva de quadra por esporte, data e horário
- Cancelamento e histórico de reservas
- Bloqueio de horários já reservados por outros usuários

## Como rodar localmente
\`\`\`bash
git clone https://github.com/eemanoel0/[nome-do-repo].git
cd [nome-do-repo]
npm install
npx json-server db.json
# abrir o index.html no navegador ou usar Live Server
